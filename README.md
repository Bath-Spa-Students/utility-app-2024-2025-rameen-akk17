Vending Machine Utility App 

This is a console-based Vending Machine program built using Python.
The application simulates a real-world vending machine experience, allowing users to browse through categorized items, select products, insert money, receive change, and even recycle bottles.

Features
		Categorized item menu (Hot Drinks, Cold Drinks, Snacks, etc.)
		Item selection via code
		Stock tracking and out-of-stock handling
		Smart item suggestions based on purchases
		Payment system with change calculation
		Bottle recycling feature
		Admin panel to:
		View current stock
		Restock all items
		Generate a sales report
		Clean UI with styled welcome/goodbye messages

Technologies Used
		Python 3
		Standard Python libraries (time, collections.defaultdict)
